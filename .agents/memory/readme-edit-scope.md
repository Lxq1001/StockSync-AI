---
name: README edit scope
description: Preserve user-authored README sections during targeted updates.
---

When making a targeted README change, preserve all unrelated sections and user-authored content.

**Why:** The user corrected an earlier edit that removed their Challenges & Learnings and Future Improvements sections while making a separate README change.

**How to apply:** Edit only the sections the user names. Do not rewrite or omit other README content unless explicitly requested.
